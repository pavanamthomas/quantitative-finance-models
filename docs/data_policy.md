# Data policy

This repository is constructed so that every numerical illustration can be
reproduced from the source code, a documented random seed, and closed-form
identities. It does not ship, download, or cache third-party market datasets.

## What is permitted

- Simulated price and return paths generated by documented stochastic
  specifications (independent Gaussian draws, one-factor CAPM-style
  constructions, and simple GARCH(1,1) recursions).
- Cash-flow schedules implied by a contract description (coupon bonds,
  level annuities, option strikes).
- Closed-form quantities that follow from a stated formula (Black–Scholes,
  annuity present value, unconstrained global-minimum-variance weights).

## What is excluded

- Vendor or exchange historical prices, yields, option surfaces, or
  alternative-data files.
- Scraped web series and undocumented CSV dumps.
- Any pipeline that would require `yfinance` or an analogous market-data
  client.

If a reader wishes to apply the same estimators to an external series, that
work belongs outside this repository. Bring-your-own data is compatible with
the functions, but those series must not be committed here.

## Reproducibility

Demonstration scripts and tests fix a NumPy `Generator` seed where randomness
is used. Changing the seed changes the simulated path; it does not change the
algebraic identities under test (put–call parity, annuity closed forms, the
sign of duration).

## Interpretation

A simulated path is a draw from a model, not a sample from a market. Moments
estimated on simulated data recover the simulator by construction when the
sample is large and the specification is correct. That recovery is a numerical
check, not empirical evidence about asset markets.
